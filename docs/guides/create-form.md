# Create a form (screen)

1. Configuration → Forms → Create draft.
2. Set theme id (`oms-default` / `oms-attention`).
3. Add layout widgets (`FormFields`, `ProductList`, `CatalogSearch`, `ActionButtons`).
4. Edit fields used by `FormFields`.
5. Publish — version becomes immutable.
6. Reference from a workflow activity via **AssetRef** (no `formKey` required).
